# Termux IP Info Finder

Sebuah tool sederhana berbasis Python untuk menampilkan informasi publik tentang alamat IP Anda (lokasi, ISP, dll) langsung dari terminal Termux.

## Fitur
- Menampilkan IP publik, kota, wilayah, negara, dan ISP.
- Ringan dan hanya menggunakan library standar Python.
